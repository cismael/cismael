This repository is intended to be used as a GitHub Profile README. To update the profile appearance:
1.  Modify the `README.md` file.
2.  Ensure that all badges and external links are correctly formatted.
3.  Commit and push changes to the main branch of the repository named `cismael`.

# Development Conventions
- **Markdown Standards**: Follow GitHub Flavored Markdown (GFM).
- **Badges**: Uses external services like `img.shields.io`, `github-readme-stats`, and `github-readme-streak-stats` for dynamic content.
- **Styling**: Uses HTML tags within Markdown for alignment and layout control (e.g., `<p align="left">`, `<img>` with specific height/width).
